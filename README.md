# 使魔卡牌对战（Magic The Traveling）

单文件网页卡牌对战游戏，打开 `index.html` 即玩。在线地址：<https://lychees.github.io/Magic-The-Traveling/>

- 13 个阵营、258 张卡牌（城堡 / 壁垒 / 塔楼 / 地狱 / 墓园 / 地下城 / 据点 / 要塞 / 元素 / 中立 + HotA 新阵营：港口 / 堡垒 / 工厂，含 40 张四系法术卡）
- 人机对战 + 同机双人对战（热座模式，带交机隐私屏）
- 组牌、三排阵型、自动战斗、音效、卡面立绘，零依赖纯静态页

---

## 一、游戏流程

1. **组牌**：从牌池选 20–60 张牌（每种卡最多 4 张），满 20 张即可开战。侧栏有法力曲线和阵营统计，每张卡右上角有强度评分（白板卡锚定 60 分）。
2. **对局按"轮"进行**，每轮两个阶段：
   - **部署阶段**：双方法力水晶 +1（上限 10）并回满、各摸 1 张牌，然后出牌、拖拽布阵。人机模式下你部署完点「开始战斗」，AI 随即完成部署；双人模式下双方通过交机隐私屏依次部署。
   - **进攻阶段**：双方场上所有单位**自动战斗**，行动顺序按「攻击 + 有效护甲 + 当前生命」总和从高到低，并列随机。
3. 英雄 20 点生命，先击倒对方英雄者胜；牌库抽空后每次摸牌受到递增的疲劳伤害，双方同轮疲劳致死算同归于尽。

开局双方各摸 5 张牌，完全对称，没有先后手优势。

## 二、阵型（前 / 中 / 后三排）

- 双方场上各分**前、中、后**三排对峙。部署阶段可随时拖拽己方随从：跨排移动、同排内左右排序。
- 从手牌**点击**打出：近战默认进前排，远程默认进后排；也可以**直接把手牌拖**到目标排的指定位置。
- **反悔**：本轮刚打出且没有入场效果的随从，单击即可收回手牌并退还法力（青色虚线框提示）。
- 场上随从数量没有硬性限制（安全上限 50，正常对局不会触及）；手牌上限 10 张。

## 三、战斗规则

**攻击目标（战场宽度）**

- 每张卡占 1 点战场宽度（守备表示占 2），各排居中对齐；前排会遮挡正后方同宽度的区域。
- 近战单位只能攻击**暴露宽度 > 0** 的单位，目标按暴露宽度**加权随机**选取：
  - 例：前排 1 卡 + 后排 2 卡 → 命中概率 50% / 25% / 25%（后排各只露出一半）；
  - 前后排各 1 卡 → 后排卡在前排卡死前无法被近战攻击。
- 远程单位无视遮挡，可攻击任意一排，且**优先攻击飞行单位**；
- **飞行单位漂浮在空中，不参与战场宽度计算**（不遮挡别人、也不被遮挡，卡面有浮起特效）；
- 只有对方场上没有随从、或对方所有随从你**都够不到**时，才能直接攻击英雄；但只要对方还有**守备表示**的单位或**远程单位**，就必须先打完它们（守备墙 + 远程防线）。飞行单位守备时暂时失去飞行效果。

**伤害**

- 伤害 = 攻击 − 目标护甲（护甲每次受击都减免）；远程攻击飞行单位伤害**加倍**（先减护甲再翻倍）。
- 日志会显示每次攻击/反击的伤害数值和目标剩余生命。

**反击**

- 每个单位每战斗阶段有 **1 次**反击机会（阶段开始时重置）。
- 受到攻击伤害（含溅射）且存活时，若**够得到**伤害来源（按攻击射程规则判定）就立刻反击并消耗机会；够不到或 0 攻则不消耗，留到下次。
- 反击造成的伤害不再触发反击。
- **远程单位的攻击不会触发反击**（无论站位）；带「不受反击」特性的单位（恶魔、大恶魔）同样不会触发反击。以上免反击只对普通反击有效——**攻击守备表示的单位时，必然同时受到守备单位攻击力的反击**（无视一切免反击特性）。
- **守备表示**的单位：无限次反击，且反击与对手的攻击**同时结算**（即使被打死，反击也会生效）。

**士气系统**

- 每个单位士气 -10 ~ +10。正士气每点 = 10% 概率在行动后**额外行动一次**（每战斗阶段限一次）；负士气每点 = 10% 概率本回合**无法行动**，且反击（含守备表示的同时结算反击）有同等概率失败。
- 士气流转：造成伤害 +1、击杀额外 +1、受到伤害 -1；伤害被护甲完全抵挡时防守方 +1（守备表示格挡时伤害来源额外 -1）。
- 每轮开始时：我方战场所有单位同一阵营 → 全场 +1；两种阵营无影响；x（≥3）种阵营 → -(x-2)（单一阵营构筑有士气加成，双阵营构筑不受惩罚）。**墓园（亡灵）与元素城单位不受士气影响，也不参与阵营计算**——纯墓园/元素卡组没有阵营加成，但它们混进其他阵营时也不会拉低阵营多样性；不过我方战场存在（非盖牌）墓园单位时，所有单位士气额外 -1（亡灵削弱活人士气）。盖牌不参与士气结算（不增减、不计入阵营判定）。

**守备表示**

- 部署阶段可点击随从卡上的按钮在攻击/守备表示之间任意切换。
- 守备表示：单位不主动攻击；无限次反击且同时结算；被随机效果（火球、夺取等）选中的概率 ×2（卡面变宽两倍）。
- **守备墙**：必须消灭对方所有守备表示的单位，才能攻击对方英雄。
- 飞行单位守备时暂时失去飞行效果（可被近战攻击、不再被远程加倍）。
- 翻面单位也可切换守备表示（但依然不会主动进攻）；**盖牌守备的单位会被其它单位选中攻击，并在被攻击前揭示**（结算盖放时跳过的战吼，此后按正面守备单位结算）。守备墙计算所有守备单位（含盖牌守备）。

**翻面表示**

- 手牌卡上的「盖放」按钮可翻面表示部署（**默认守备表示**）：不触发战吼，对手只看到卡背。
- 翻面单位不会成为攻击目标、不主动攻击、不反击；但仍每轮恢复法术、可吃到 buff。
- 部署阶段可随时「翻开」翻面单位（此时结算盖放时跳过的战吼）；已在场上正面的单位不能再盖回。

**行动资格**

- 所有单位部署当轮即可参战（没有召唤失调）；0 攻单位跳过行动。

## 四、关键词条

| 词条 | 效果 |
|---|---|
| 远程 | 可攻击任意一排；优先攻击飞行单位且对其伤害加倍；攻击不触发普通反击（守备表示的反击除外） |
| 飞行 | 只能被远程或飞行单位攻击；被远程攻击时受到双倍伤害；悬浮空中不占战场宽度；正面表示时可 落地/起飞 切换 |
| 骑兵 | 攻击骑兵以外的单位时不会被反击 |
| 连击 | 攻击随从时连续攻击 2 次（第二次不触发反击；目标已死则第二次落空） |
| 反击 X | 每战斗阶段可反击 X 次（默认 1 次；皇家狮鹫反击2） |
| 拒马 | 可以对骑兵进行反击（无视骑兵的免反击） |
| 毒 LvX | 被其攻击伤害的随从中毒，每轮部署阶段开始时受到 X 点伤害 |
| 再生 X | 每轮部署阶段开始时恢复 X 点生命 |
| 分裂 | 回合开始时（再生之后），若生命值为偶数则一分为二，每个单位生命为原先一半，其它特效不变；新分裂的单位当回合不再分裂和再生 |
| 吸血 | 造成的伤害等量恢复自身生命 |
| 范围攻击 | 攻击随从时，对其左右相邻的随从造成等量溅射 |
| 石化 | 生命未满时护甲视为 4 |
| 法术护盾 X | 受到的法术伤害 -X |
| 火系魔法免疫 | 不受火系法术影响（凤凰 / 火鸟 / 火精灵 / 烈火精灵 / 火元素 / 烈火元素） |
| 法力燃烧 X | 攻击敌方英雄时，对方下一轮法力 -X |
| 驱魔 | 被该单位击杀的随从不触发亡语 |
| 三姐妹 | 场上每多一种不同名的鹰身女妖，我方全体鹰身女妖 +1 攻 / +1 血上限 |
| 恐狼光环 | 同排左右相邻的友方随从 +1 攻击（多只可叠加） |
| 和平 | 不会发起可能令自己死亡的攻击（若目标反击会致死则跳过） |
| 死亡凝视 | 攻击时 25% 概率直接消灭目标随从（无视生命与护甲，蛮牛） |
| 复仇 X | 每次反击前攻击 +X（永久累积，深渊海蛇） |
| 鼓舞 X | 战斗阶段开始前，我方所有单位士气 +X（大天使） |
| 威吓 X | 战斗阶段开始前，敌方所有单位士气 -X（鬼龙） |
| 护甲穿透 X | 攻击无视目标 X 点护甲（比蒙 / 比蒙巨兽 / 弩手） |
| 不受反击 | 攻击不触发普通反击（守备表示的同时结算反击除外，恶魔 / 大恶魔） |

典型战吼/亡语：祭司祈祷（其他友方 +1 攻/+2 血）、魔女火球（随机敌方随从 1d6）、魅魔夺取（随机获得一个敌方随从）、死神（消灭攻击力最高的敌方随从）、龙女（下一轮准备阶段变身为 8/0/16 绿龙并恢复 4 点生命，期间可被击杀）、大天使（战吼·复活：将墓地中最后死亡的随从满状态复活到其原排）、骷髅系（亡语检索同名卡）、木乃伊系（亡语诅咒：敌方全场 -1 攻）、死灵法师系（战吼召唤骷髅）、骨龙系（打出时除外墓地牌，每张费用 -1）、小精灵系（战吼本回合法力 +1）、医护兵（战吼治疗英雄）。

## 五、法术卡牌

- 法术卡（紫色描边 + 系别徽标：土棕 / 水蓝 / 火红 / 气青 + 「法术」标签）是一类特殊卡牌：从手牌打出后**不入场**，效果结算完进入墓地（可被骨龙减费利用）。组牌界面中法术卡独立成「法术」大分区，按土 / 水 / 火 / 气四系分组。
- 无需目标的法术（如 治疗、末日审判、召唤气元素）点击直接结算；需要目标的法术（如 冰箭、护体石肤、驱散）点击后进入选目标模式：合法目标高亮，点击目标结算，点击空白处或再点一次该法术卡取消。
- 法术卡也可以**盖放**：成为场上的一张盖牌（不是单位、不会被攻击），部署阶段翻开的瞬间立即结算——需要目标的法术翻开时随机选一个合法目标，无合法目标则不生效。
- 法术伤害受「法术护盾 X」减免；被法术杀死的随从正常进墓地并触发亡语。
- AI 与联机双方都会使用法术卡。
- 当前共 40 张法术卡：土系（护体石肤 / 迟缓 / 地刺 / 死亡波纹 / 护体神盾 / 陨石 / 复活术 / 雷鸣爆弹 / 聚灵奇术 / 召唤土元素 / 流沙 / 召唤骷髅兵）、水系（治疗 / 冰箭 / 祝福 / 驱散 / 治疗波动 / 镜像术 / 传送 / 失忆 / 召唤水元素 / 召唤史莱姆）、火系（火球术 / 嗜血奇术 / 烈火神盾 / 末日审判 / 烧灼 / 地狱烈焰 / 混乱 / 流星火雨 / 召唤火元素 / 狂暴）、气系（闪电箭 / 连锁闪电 / 召唤气元素 / 龙卷 / 鼓舞 / 召唤雷元素 / 龙卷风 / 大气神盾）。

组牌侧栏提供一键填充的预设卡组（遵守每种 ≤4 与拥有数上限）：

- **帕斯卡 · 海精灵**（31 张）：以 HotA 港口兵种线为骨架（泉水精灵/海洋精灵/水手/海员/海贼/皇家海盗/暴风鸟/暴风雕/海洋女巫/海洋术士/鱼人/海蛇），配主角卡【帕斯卡】（你施放的水系法术 -1 费，单位法术「巨浪」清敌方前排）与招牌水系法术【旋涡】，再加水系治疗/冰箭/治疗波动/镜像术。
- **艾达 · 学者**（30 张）：以法师系与施法者单位（法师/大法师/僧侣/大祭司/魔女/精灵法师/祭司）为骨架，配主角卡【艾达】（你施放的任意法术 -1 费，单位法术「研读」摸牌）与大量四系法术（冰箭/闪电箭/火球术/连锁闪电/祝福/驱散/镜像术/治疗/龙卷风）。

## 五、实用操作

- **双击**任意卡牌：查看大图详情（特性说明、当前状态、强度评分）。
- **单击**牌库 / 墓地区域：查看剩余卡牌（不暴露顺序）和死亡随从列表。
- 单击手牌 = 出牌（有约 0.2 秒确认延迟，双击则取消出牌改为看详情）。
- 顶栏 🔊/🔇 切换音效（首次点击页面后音效才会启用）。

## 六、收藏与卡包

- 首次运行即拥有**全卡收藏**（77 种卡各 4 张）+ 200 金币，组牌不受限。
- 对局结算获得金币：胜 100 / 平 50 / 负 30；卡包 100 金币一包，每包 5 张随机卡（全卡池、可重复），逐张点击翻开，按评分分稀有度光晕（灰/蓝/紫/金）。
- 收藏与金币保存在浏览器 localStorage，清缓存会丢失。

## 七、双人同机对战

- 组牌界面顶部切换「双人对战」：玩家 1 组牌 → 交机 → 玩家 2 组牌 → 开战。
- 每轮部署阶段双方**依次**部署，交机隐私屏保证互相看不到手牌；当前部署方始终显示在下方半场。
- 进攻阶段双方手牌均盖卡背观战。

## 八、卡牌强度评分

组牌界面每张卡显示 1–100 的强度评分：所有白板卡（无任何特效）锚定 **60 分**，特效卡按「数值预算 + 特效折算 + 模拟对战校准」评分，全卡池当前分布在 48–68 分。预算线：V = 3 × 费用 + 2（攻击 + 生命 + 2×护甲）。

## 卡牌数据维护

卡牌数据已经 **JSON 驱动**：唯一数据源是根目录的 **`cards.json`**，游戏运行时从 `index.html` 内嵌的 `<script type="application/json" id="cards-json">` 块同步解析（`loadCardData()`），不再有硬编码的卡牌数组。

**加卡 / 改卡流程**：

1. 编辑 `cards.json`，在 `cards` 数组里增改条目（顶部 `_comment` 字段逐字段说明了全部可用字段：name/race/cost/atk/arm/hp/rating/traits/spell/spellParam/actSpell/spellCost/spellMana0/spellManaMax/actSpells/type/school/spellEffect/target/art/token）。
2. 运行 `node tools/sync-cards.js`：先全量校验（必填 name/race/cost、race ∈ races、法术 target 合法、数值字段有限、traits/actSpells/art 结构正确），通过后才把 cards.json 注入 index.html 的内嵌块；校验失败会打印全部错误且**不修改** index.html。
3. 刷新页面即可（GitHub Pages 部署时 cards.json 与 index.html 一并提交）。

新增机制（新战吼/新法术效果/新特性）仍需在 index.html 对应引擎处登记（`battlecry` / `resolveSpellEffect` / `TRAIT_TEXT` / `UNIT_SPELL_TEXT`），但纯数值卡与新组合（已有机制的新卡）只需改 cards.json。

## 本地运行 / 部署

纯静态单文件，无需构建：直接双击 `index.html`，或任意静态服务器托管。GitHub Pages 部署为 `main` 分支根目录。
