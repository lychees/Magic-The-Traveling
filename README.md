# 使魔卡牌对战（Magic The Traveling）

单文件网页卡牌对战游戏，打开 `index.html` 即玩。在线地址：<https://lychees.github.io/Magic-The-Traveling/>

- 4 个种族、77 张卡牌（人族 / 精灵族 / 魔物族 / 不死族）
- 人机对战 + 同机双人对战（热座模式，带交机隐私屏）
- 组牌、三排阵型、自动战斗、音效、卡面立绘，零依赖纯静态页

---

## 一、游戏流程

1. **组牌**：从牌池选 20–60 张牌（每种卡最多 4 张），满 20 张即可开战。侧栏有法力曲线和阵营统计，每张卡右上角有强度评分（白板卡锚定 60 分）。
2. **对局按"轮"进行**，每轮两个阶段：
   - **部署阶段**：双方法力水晶 +1（上限 10）并回满、各摸 1 张牌，然后出牌、拖拽布阵。人机模式下你部署完点「开始战斗」，AI 随即完成部署；双人模式下双方通过交机隐私屏依次部署。
   - **进攻阶段**：双方场上所有单位**自动战斗**，行动顺序按「攻击 + 有效护甲 + 当前生命」总和从高到低，并列随机。
3. 英雄 30 点生命，先击倒对方英雄者胜；牌库抽空后每次摸牌受到递增的疲劳伤害，双方同轮疲劳致死算同归于尽。

开局双方各摸 5 张牌，完全对称，没有先后手优势。

## 二、阵型（前 / 中 / 后三排）

- 双方场上各分**前、中、后**三排对峙。部署阶段可随时拖拽己方随从：跨排移动、同排内左右排序。
- 从手牌**点击**打出：近战默认进前排，远程默认进后排；也可以**直接把手牌拖**到目标排的指定位置。
- **反悔**：本轮刚打出且没有入场效果的随从，单击即可收回手牌并退还法力（青色虚线框提示）。
- 场上随从数量没有硬性限制（安全上限 50，正常对局不会触及）；手牌上限 10 张。

## 三、战斗规则

**攻击目标**

- 近战单位只能攻击对方**最前排**（有随从的最前一排）的单位；
- 远程单位可攻击任意一排，且**优先攻击飞行单位**；
- 只有对方场上完全没有随从时，才能攻击英雄本体。

**伤害**

- 伤害 = 攻击 − 目标护甲（护甲每次受击都减免）；远程攻击飞行单位伤害**加倍**（先减护甲再翻倍）。
- 日志会显示每次攻击/反击的伤害数值和目标剩余生命。

**反击**

- 每个单位每战斗阶段有 **1 次**反击机会（阶段开始时重置）。
- 受到攻击伤害（含溅射）且存活时，若**够得到**伤害来源（按攻击射程规则判定）就立刻反击并消耗机会；够不到或 0 攻则不消耗，留到下次。
- 反击造成的伤害不再触发反击。
- 推论：躲在后排的远程单位可以无伤输出；站在前排的远程单位会被近战反击。

**行动资格**

- 所有单位部署当轮即可参战（没有召唤失调）；0 攻单位跳过行动。

## 四、关键词条

| 词条 | 效果 |
|---|---|
| 远程 | 可攻击任意一排；优先攻击飞行单位且对其伤害加倍 |
| 飞行 | 只能被远程或飞行单位攻击；被远程攻击时受到双倍伤害 |
| 骑兵 | 攻击骑兵以外的单位时不会被反击 |
| 毒 LvX | 被其攻击伤害的随从中毒，每轮部署阶段开始时受到 X 点伤害 |
| 再生 X | 每轮部署阶段开始时恢复 X 点生命 |
| 分裂 | 回合开始时（再生之后），若生命值为偶数则一分为二，每个单位生命为原先一半，其它特效不变；新分裂的单位当回合不再分裂和再生 |
| 吸血 | 造成的伤害等量治疗己方英雄 |
| 范围攻击 | 攻击随从时，对其左右相邻的随从造成等量溅射 |
| 石化 | 生命未满时护甲视为 4 |
| 法术护盾 X | 受到的法术伤害 -X |
| 法力燃烧 X | 攻击敌方英雄时，对方下一轮法力 -X |
| 驱魔 | 被该单位击杀的随从不触发亡语 |
| 三姐妹 | 场上每多一种不同名的鹰身女妖，我方全体鹰身女妖 +1 攻 / +1 血上限 |

典型战吼/亡语：祭司祈祷（其他友方 +1 攻/+2 血）、魔女火球（随机敌方随从 1d6）、魅魔夺取（随机获得一个敌方随从）、死神（消灭攻击力最高的敌方随从）、龙女（下一轮准备阶段变身为 8/0/16 绿龙并恢复 4 点生命，期间可被击杀）、骷髅系（亡语检索同名卡）、木乃伊系（亡语诅咒：敌方全场 -1 攻）、死灵法师系（战吼召唤骷髅）、骨龙系（打出时除外墓地牌，每张费用 -1）、小精灵系（战吼本回合法力 +1）、医护兵（战吼治疗英雄）。

## 五、实用操作

- **双击**任意卡牌：查看大图详情（特性说明、当前状态、强度评分）。
- **单击**牌库 / 墓地区域：查看剩余卡牌（不暴露顺序）和死亡随从列表。
- 单击手牌 = 出牌（有约 0.2 秒确认延迟，双击则取消出牌改为看详情）。
- 顶栏 🔊/🔇 切换音效（首次点击页面后音效才会启用）。

## 六、双人同机对战

- 组牌界面顶部切换「双人对战」：玩家 1 组牌 → 交机 → 玩家 2 组牌 → 开战。
- 每轮部署阶段双方**依次**部署，交机隐私屏保证互相看不到手牌；当前部署方始终显示在下方半场。
- 进攻阶段双方手牌均盖卡背观战。

## 七、卡牌强度评分

组牌界面每张卡显示 1–100 的强度评分：所有白板卡（无任何特效）锚定 **60 分**，特效卡按「数值预算 + 特效折算 + 模拟对战校准」评分，全卡池当前分布在 48–68 分。预算线：V = 3 × 费用 + 2（攻击 + 生命 + 2×护甲）。
