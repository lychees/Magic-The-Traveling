# Roguelike 闯关模式设计

> 目标：借鉴《邪恶铭刻》（Inscryption）的优点——roguelike 结构、规则型 Boss、献祭与仪式感；
> 规避它的缺点——平衡失控、构筑靠天吃饭、AI 太弱、规则含糊、死亡卡强度失控。

## 1. 为什么做闯关模式

- 我们的痛点（AI 不够强、PVP 平衡压力大）在闯关结构里天然缓解：玩家是在"解题"，不是在公平竞技。
- 现有资产可直接复用：274 张卡池、13 阵营、士气/守备/盖牌体系、金币/卡包经济、集卡册。

## 2. 引入的优点

### 2.1 地图与节点

- 10 列分支地图（预生成）：固定列（起点/中 Boss 第 5 列/最终 Boss 第 10 列）1 个节点，其余列 2-3 个可选节点，逐层点击选路，选后锁定。
- 节点间连线约束（杀戮尖塔式）：每个节点只连通下一列最近的 1-2 个节点，未连通节点置灰不可选；单节点列全连出/全汇入。
- 节点类型：战斗 / 精英 / 篝火 / 商店 / 事件 / 中 Boss / 最终 Boss，按列位加权分布（前期战斗为主，中后期混入精英与休整点）。

### 2.2 规则型 Boss（不追求更强 AI，而是改规则）

| Boss | 规则修饰 | 说明 |
| --- | --- | --- |
| 万籁俱寂（中 Boss） | 敌方每轮准备阶段召唤一个【骷髅】到前排 | 逼迫玩家抢节奏，不能拖 |
| 心如止水（中 Boss 轮换池） | 全场所有单位士气锁定为 0 | 抹掉士气体系，纯三围肉搏 |
| 巨龙威压（最终 Boss） | 敌方所有单位攻击力 +1 | 最朴素的数值压迫，检验构筑成型度 |

### 2.3 抓牌与构筑修正（规避"构筑靠天吃饭"）

- 每场战斗胜利后三选一（阵营 + 中立池，按 rating 加权），可跳过。
- 商店提供：删牌（50🪙）、买阵营卡（100🪙）、治疗（40🪙）——构筑修正手段是《邪恶铭刻》缺的关键一环。

### 2.4 篝火：风险决策

- 选一张牌：70% 永久 +1攻/+2血（克隆同名卡，只影响该张），30% 销毁。
- 或者选择稳妥：恢复 8 点英雄生命。

### 2.5 生命继承

- 英雄生命在节点间继承（初始 25），篝火/商店是治疗的主要来源——制造"每一滴伤害都有分量"的压力。

### 2.6 死亡纪念卡（规避强度失控）

- 失败时按本局数据生成纪念卡：攻击 = min(12, 总击杀)，生命 = min(15, 存活轮数)，费用 = min(10, 击杀/2)，rating 恒 60。
- 只进收藏与集卡册（纪念品），不追求构筑强度——原版死亡卡"要么废物要么超模"的问题就此消解。

## 3. 规避的缺点（设计铁律）

1. **所有循环收益必须有计数器**（每回合/每阶段/每单位一次），评审新卡时强制检查。
2. **高费卡必须值得亏节奏打出**：7 费+ 卡的评审看"当回合场面影响力"，不合格就加强或降费。
3. **构筑修正必备**：三选一可跳过、商店可删牌、篝火可稳定治疗——闯关不允许"抓不到体系就等死"。
4. **词条描述一行说清**，复杂结算进检索页；结算顺序以玩法手册为准。

## 4. 与现有系统的接口

- `initGame(runDeck, 'ai', enemyDeck)`：enemyDeck 透传（AI 模式也接受自定义敌方牌组）。
- `checkGameOver`：闯关战役胜利/失败分流到奖励/纪念流程，不走常规金币结算浮层。
- Boss 修饰挂在三处：`summonMinion`（巨龙威压）、`changeMorale`（心如止水）、`startRound`（万籁俱寂）。
- 生命继承：战斗结束后 `RUN.hp = state.player.hp`，下一场战斗初始化后覆盖 `state.player.hp/maxHp`。
- 通关/失败奖励走既有金币与收藏经济（`gold`/`collection`/`saveEconomy`），集卡册自动受益。

## 5. 后续迭代方向

- 随机事件池扩充、连线可视化（画出节点间的实际连线）。
- 每日种子 + 进阶难度层（敌方 +2 血、士气锁定 -1 等词条层）。
- 献祭小体系（墓园 5-8 张新卡 + 「血祭」词条：打出时可献祭友方单位减费/增益），与聚灵奇术形成复活循环。
- 闯关战绩（通关次数、最深层数）进个人统计。
