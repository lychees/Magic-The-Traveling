# 《使魔卡牌对战》平衡性与体验评审

> 评审日期：2026-08-21 · 基于当前版本（264 张卡 / 13 阵营 / JSON 数据驱动）
> 数据基础：300 局随机牌组模拟 + 78 组阵营卡组对阵（2340 局）

## 一、数据快照

| 指标 | 数值 | 解读 |
|---|---|---|
| 平均对局长度（旧 AI，几乎不用守备） | 8.1 轮（中位 8，最短 3，最长 17） | 初测：节奏偏快 |
| 平均对局长度（新 AI，善用守备托局） | **9.3 轮（中位 8，最短 3，最长 29）** | 善用守备后节奏放慢约 15%，长尾显著拉长 |
| 7 费以上卡打出占比 | 14.6% → 15.1%（总出牌量 2547 → 3132） | 守备托局后整体出牌量上升，高费卡略增 |

| 阵营卡组胜率极差 | 18% ~ 83%（墓园 vs 塔楼） | 主要反映生成规则偏好，但也暴露阵营曲线断层 |

## 二、不平衡问题

### B1. 曲线过快，高费卡结构性弱势（核心问题）
法力每轮 +1，8–10 费单位理论第 8–10 轮上场，但对局平均 8 轮结束、最短 3 轮。快攻 4 费铺满地时高费卡还在手牌里。这导致：
- 牌组构建天然偏向 1–4 费，高分高费卡（泰坦/比蒙/圣龙/天使）出场率低；
- 阵营强度排行中"保留低费快攻的卡组"（塔楼 82.8%）碾压"高费核心被裁的卡组"（据点/墓园 ~17%）。

**建议**：第 5 轮起水晶每轮 +2（或第 6 轮起），让 7–10 费卡在终盘前 2–3 轮登场；配合每局一次的手牌调度（开局换 2 张），降低高费卡沉底惩罚。

**进展（2026-08-21 复测）**：已将游戏 AI 与测试策略的守备姿态升级为反应型（低攻高血筑墙 + 危局大身板转守备），平均对局长度 8.1 → 9.3 轮、最长 29 轮，证明托局机制有效。但 9–10 费单位依然压在终盘线，水晶加速与手牌调度仍然值得做（优先级由 P0 下调为 P1）。

### B2. 行动顺序放大面板差距
行动顺序 = 攻击+有效护甲+当前生命总和降序。高面板单位永远先动先杀，低费单位抱团也抢不到先手——"又大又快"没有反制维度，玻璃炮（棕熊 5/9）优先级还异常高。

**建议**：行动顺序改为纯攻击力降序（甲/血不参与），或引入"速度"分层——让低费快攻能抢在大怪前出手一次，形成 快攻→控制→大怪 的循环克制。

### B3. 史莱姆分裂的指数增殖只是被盖住，没有治好
「偶数血分裂 + 再生」每轮翻倍，50 上限只是防卡死的补丁。配合祈祷（+2 血永远偶数）中期必然爆炸式铺场，且铺出来的史莱姆互为犄角（宽度遮挡）。

**建议**：每个单位每局最多分裂 1 次（复制体不再分裂），或分裂消耗生命上限（子体 maxHp 同样减半，使三代后自然消亡）。

### B4. 预设卡组法术同质化
所有阵营默认卡组统一塞 雷鸣爆弹×4 + 连锁闪电×2——两张顶评法术抹平了阵营法术差异，也让这两张卡使用率畸形。

**建议**：按阵营风格配法术（快攻配火系直伤、慢速配土系护盾/复活、水系给治疗过牌），并把聚灵奇术/召唤史莱姆这类"体系法术"优先给对应阵营。

### B5. 墓园的双重隐性削弱
纯墓园卡组没有同阵营 +1，混编墓园还要全场 -1（"墓园在场惩罚"），而墓园单位自己又吃不到士气——墓园在所有士气维度都是纯付出无回报（阵营胜率 16.9% 垫底印证）。

**建议**：纯墓园阵容视为满足同阵营 +1（亡灵士气锁 0 但不再额外 -1）；或给墓园专属补偿机制（如骷髅海分裂/招魂触发时全场墓园 +1 攻）。

## 三、不合理问题

### R1. 玩家代理感弱，对局在"看戏"
自动战斗下玩家决策只有：组牌、出牌时机、布阵、法术目标。攻击目标全由加权随机/启发式决定，同一场面结果方差大。长按战术预览缓解了可读性，但不改变"不可控"。

**建议**：每回合每单位允许标记 1 个「集火目标」（单击自己单位 → 单击敌方），被标记目标在 AI 选目标权重中 ×3。这是给玩家一个低学习成本、高战术价值的主控点。

### R2. 免反击语义重叠，规则认知负担重
现在有四套相近规则：远程不触发反击 / 骑兵不被非骑兵反击 / 恶魔不受反击 / 守备必反击（但不反远程）。玩家需要记一张"谁能反击谁"的矩阵。

**建议**：统一为一个「反击射程」模型——反击 = 一次攻击（遵守普通攻击的射程与宽度规则），守备表示的特殊性只保留"无限次 + 同时结算"。词条数量随之可砍 1–2 个。

### R3. AI 单一且偏弱
AI 只有一套贪心策略 + 随机牌组，打过几局就能稳定针对（后场远程、守备墙）。

**建议**：三档难度——贪心快攻 / 保守控制（重守备墙+后场远程+治疗） / 组合技（优先凑三姐妹、骷髅海、史莱姆分裂）。选择难度显示在组牌界面。

### R4. 守备墙 + 远程防线 + 宽度遮挡三层护脸
打脸需要：清守备墙 → 清远程 → 穿过宽度遮挡。慢速局可能重新拖长（目前平局率 0 是因为疲劳兜底，但过程可能冗长）。

**建议**：守备表示同时最多 2 个单位生效（第 3 个守备单位不形成墙），或远程防线只挡近战（远程英雄直击不受远程单位限制）。

## 四、不有趣问题

### F1. 金币经济断档
首次运行即送全卡收藏，金币只剩"开包加库存数量"这一几乎无感的用途，对局奖励失去目标感。

**建议**：增加非强度消费——卡背皮肤、异画卡面（同卡不同 art hue）、英雄头像、开包限定"闪卡"（纯展示）。让每局 +100/50/30 重新有意义。

### F2. 英雄没有个性
帕斯卡/艾达开了主角卡的头，但阵营没有"英雄"概念——13 个阵营玩起来差异只在卡池。

**建议**：每个阵营一张英雄卡（自带英雄技能，如 墓园英雄"每死一个友方骷髅招魂 1"），预设卡组默认带本阵营英雄，PVE 可加英雄对英雄的特殊规则。

### F3. 没有对局沉淀
没有回放、没有战绩、没有成就。打完就完了。

**建议**：战绩面板（各模式胜场、最爱阵营、最高连胜），战斗日志可一键复制导出。

### F4. 结算仪式感不足
胜利/失败只有一行文字 overlay。

**建议**：胜利时放史诗音效 + 展示本局 MVP 单位（输出最高），失败时给出死因分析（被谁击杀）。

## 五、调整优先级

| 优先级 | 事项 | 预期收益 |
|---|---|---|
| P0 | 集火标记（R1） | 玩家代理感质变，方差可控 |
| P1 | 第 5 轮起水晶 +2 + 开局手牌调度（B1，已被守备策略部分缓解） | 高费卡进一步前移 |
| P1 | ~~AI 守备策略~~（已完成：危局筑墙，平均轮次 +15%） | 对局节奏回归健康 |
| P1 | 行动顺序改纯攻击降序（B2） | 快攻/大怪循环克制成型 |
| P1 | 预设法术按阵营风格化（B4） | 阵营个性与法术使用率均衡 |
| P1 | 史莱姆分裂限 1 次（B3） | 移除中期爆炸铺场 |
| P2 | 墓园士气补偿（B5） | 第 13 阵营可用 |
| P2 | AI 三档难度（R3） | PVE 寿命 |
| P2 | 非强度消费（F1） | 金币经济闭环 |
| P3 | 反击射程统一（R2）、战绩面板（F3）、阵营英雄（F2）、结算仪式感（F4）、守备墙上限（R4） | 长期打磨 |
