# 引擎结算顺序（与 index.html 代码一一对应）

> 本文档是战斗引擎结算流程的权威描述，改动结算顺序时必须同步更新。
> 对应代码位置以函数名为锚点（行数随重构漂移，故不标注）。

## 一、回合开始（`startRound`，双方部署阶段开始时）

按以下顺序结算（`state.round++`、phase 置为 deploy 后，**对每一方**依次执行）：

1. **法力**：`maxMana +1`（不超过 `manaCap()`，默认 10）；`mana = maxMana − burned`；`burned` 清零（法力燃烧只影响一轮）。
2. **龙女变形**：带 `pendingTransform` 的单位变为绿龙（8/0/16，清空词条与法术），英雄恢复 4 点生命。
3. **再生**：`再生X` 单位恢复 X 点生命（不超过上限）。
4. **中毒**：中毒单位受到毒素层数伤害（此时死亡不触发反击，进墓地正常触发亡语）。
5. **失明/石化倒计时**：持续回合 −1，归零时记日志（解除）。
6. **清理死亡**（`cleanupDead`）：毒死/再生期死亡的单位进墓地、触发亡语。
7. **士气环境**：
   - 我方战场存在非盖牌墓园单位 → 所有参与士气计算的单位 −1（亡灵削弱活人士气）。
   - 阵营多样性：全场同一阵营 → +1；两种 → 不变；x（≥3）种 → −(x−2)。
   - 墓园/元素单位与盖牌：不参与计算也不受影响。
8. **单位法力**：拥有单位法术的单位 `spellMana +1`（不超过 `spellManaMax`）。
9. **骷髅王李奥锐克归来**：墓地中标记 `_leoricReturn` 的单位回到原排（场上达上限则失败；返场当轮不再回蓝）。
10. **生还的宝礼**（`lifeBoonProc`）：按本步从墓地召唤的次数摸牌。
11. **摸一张牌**（`drawCard`）：牌库空则疲劳伤害递增（双方同轮疲劳致死 = 同归于尽）。
12. （闯关 Boss【万籁俱寂】：敌方召唤一个骷髅到前排。）
13. `checkGameOver` → `render`。

双人/联机模式随后确定本轮部署方（`deploySide`，每轮轮换先手）。

## 二、部署阶段

- 出牌合法性（`playCard`）：费用 ≤ 当前法力、场上 < 上限（50）；法术卡走 `playSpellCard`（不入场，结算后进墓地；盖放则成盖牌壳）。
- **反悔**（`recallMinion`）：本轮刚打出且无入场效果的单位可单击收回手牌并退还法力（已使用法术/有战吼的不可收回）。
- **姿态**：部署阶段可在攻击/守备表示间任意切换；飞行单位正面表示时可在飞行/落地间切换；盖牌默认守备表示，可翻开后结算战吼。
- 手牌上限 10 张（超出摸牌即弃）。

## 三、进攻阶段开始（`startCombat`）

1. 结算未执行的单击出牌、清除法术选目标模式。
2. AI 模式：AI 连续部署（`aiPlayStep`）→ 施放单位法术（`aiCastSpells`）→ 守备姿态（`aiSetDefense`，攻击 ≤1 的单位转守备）。
3. **鼓舞/威吓光环**（战斗阶段开始前）：双方分别结算——己方全场 `鼓舞X` 求和后我方全员士气 +X；`威吓X` 求和后敌方全员 −X（盖牌不算）。
4. **重置反击机会**：每单位 `counterLeft = max(1, 反击X)`；额外行动标记清零。
5. `combatTick` 循环（每次行动间隔 650ms）。

## 四、每次行动（`combatTick` → `nextActor` → `autoAttack`）

1. **行动者选择**（`nextActor`）：在可行动单位（`canAttack`、非守备、非盖牌、未失明/石化/未觉醒）中取 `speedOf`（攻击+有效护甲+当前生命；骑兵 ×2）最高者；并列随机。
2. **负士气判定**：士气 < 0 时 |x|×10% 概率本回合无法行动（跳过，播放低落特效）。
3. **目标选择**（`autoAttack`）：
   - 近战：战场宽度模型（`meleeTargets`）——前排遮挡正后方同宽度区域，目标按**暴露宽度加权随机**（守备表示占 2 宽）；「和平」排除自杀目标（反击会致死的）。
   - 远程：无视遮挡任意选排，**优先飞行单位**；随后按"能击杀且自己不被反击死"择优，否则打剩余生命最低者；「刺客」优先更靠后的单位。
   - 无法选择随从时：对方场空、或所有单位都够不到 → 直接攻击英雄；但对方仍有**守备表示单位或远程单位**时必须先打完（守备墙/远程防线）。
4. **伤害**（`attackDamage` / `dealAttackDamage`）：伤害 = 攻击 − 有效护甲（每次受击减免；护甲穿透 X 无视 X 点）；远程打飞行 **×2**（先减甲再翻倍）；破法打带法术单位 ×2。
5. **反击**（`executeCounter`）：
   - 每单位每战斗阶段默认 1 次（`反击X` 为 X 次），阶段开始时重置。
   - 受伤存活的单位若够得着伤害来源（按射程规则）且攻 > 0，立即反击并消耗机会；够不到或 0 攻不消耗。
   - 反击伤害**不再触发反击**；远程攻击不触发普通反击；「不受反击」特性同理。
   - **守备表示**：无限次反击、与对手攻击**同时结算**（被杀也反击），但守备单位不能反击远程；攻击守备单位时无视一切免反击特性。
6. **士气流转**：造成正面伤害 +1、击杀额外 +1；受到伤害 −1；伤害被护甲完全抵挡时守方 +1、伤害来源 −1。
7. **死亡**：先晃动再消失（幽灵卡动画），进墓地并结算亡语（亡语召唤物此时入场）。
8. **正士气**：行动后士气 > 0 时 x×10% 概率**额外行动一次**（每战斗阶段限一次，播放高涨特效）。
9. 全部行动完 → 回到 `startRound` 进入下一轮。

## 五、游戏结束（`checkGameOver`，每个结算点后调用）

- 任一英雄生命 ≤ 0 即结束（同轮双死 = 同归于尽；闯关模式平局算涉险过关，1 血续命）。
- 普通结算：胜 100🪙 / 平 50🪙 / 负 30🪙；闯关模式分流到奖励/纪念流程（`roguelikeBattleEnd`）。
